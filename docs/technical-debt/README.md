# Active Technical Debt

This directory records confirmed engineering debt that is not yet closed.
Entries must describe current evidence, ownership, and an explicit closure
condition. Completed implementation histories belong under
[`../finished/`](../finished/), while future product work belongs under
[`../requirements/`](../requirements/).

An active ledger may retain a clearly separated closed-items section for audit
history, but closed entries must not remain in its active summary or roadmap.
